# DesktopOrganizer.Core

Независимая от Windows и UI библиотека доменных моделей и интерфейсов.

- `Models/Fence.cs` — неизменяемая модель группы с Id, Name, X, Y, Width, Height.
  Имя обрезается по краям, ограничено 100 символами и не может быть пустым.
  Управляющие символы запрещены; координаты должны быть конечными,
  размеры — конечными и больше нуля; Id не может быть Guid.Empty.
- `Storage/IFenceStore.cs` — контракт загрузки и сохранения, результат загрузки
  с предупреждением и признаком доступности записи, исключение сохранения.

Интеграция с рабочим столом на этом этапе не реализуется.

Не добавлять ссылки на App, Infrastructure, WPF или Windows Desktop API.
