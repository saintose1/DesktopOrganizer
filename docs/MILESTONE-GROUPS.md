# Проверка milestone: группы и сохранение

## Запуск

В PowerShell:

```powershell
cd path\to\DesktopOrganizer
& ./.tools/dotnet/dotnet.exe run --project src/DesktopOrganizer.App
```

Также можно открыть `src/DesktopOrganizer.App/bin/Debug/net10.0-windows/DesktopOrganizer.App.exe`.
Если приложение уже открыто с той же папкой данных, второй экземпляр сообщит об этом и завершится.

## Основной сценарий

1. Нажмите «Новая группа» дважды. В списке должны появиться две группы.
2. Выберите одну и введите название `Работа`, X `120`, Y `80`, ширину `450`, высоту `350`.
3. Нажмите «Применить». Название и параметры должны обновиться в списке;
   внизу окна должно появиться сообщение «Сохранено групп: 2».
4. Выберите вторую группу и нажмите «Удалить». Она должна исчезнуть.
5. Закройте окно и запустите приложение снова той же командой.
   Должна остаться группа `Работа` с X=120, Y=80, Width=450, Height=350.
6. Введите ширину `0` и нажмите «Применить». Должно появиться сообщение
   о недопустимом размере; в списке должна остаться ширина 450.
7. Проверьте пустое название и нечисловую координату аналогичным способом.
   Затем исправьте ввод и примените корректные параметры: ошибка должна исчезнуть.

Поля являются черновиком до нажатия «Применить». Создание, удаление
и применённые изменения сохраняются автоматически, отдельная кнопка сохранения не нужна.

## Файлы и логирование

- Группы: `%LOCALAPPDATA%/DesktopOrganizer/fences.json`.
- Логи: `%LOCALAPPDATA%/DesktopOrganizer/Logs/desktop-organizer-YYYYMMDD.log`.
- В логе должны появляться события загрузки и сохранения количества групп,
  запуска и завершения приложения. Ошибки чтения и записи содержат исключение.

## Повреждённый JSON: отдельная тестовая папка

Чтобы проверить этот сценарий отдельно от обычных данных, закройте приложение и запустите:

```powershell
& ./.tools/dotnet/dotnet.exe run --project src/DesktopOrganizer.App -- --StorageDirectory "$PWD/.tools/manual-check"
```

Создайте группу и закройте окно. Затем в PowerShell:

```powershell
Set-Content -LiteralPath ./.tools/manual-check/fences.json -Value '{broken json' -Encoding utf8
& ./.tools/dotnet/dotnet.exe run --project src/DesktopOrganizer.App -- --StorageDirectory "$PWD/.tools/manual-check"
```

Ожидаемый результат: приложение открывается с пустым списком и жёлтым предупреждением.
В `.tools/manual-check` остаётся файл `fences.json.corrupt-*` с исходным содержимым.
Новая группа создаётся и сохраняется; после следующего запуска она восстанавливается.
Если исходный файл невозможно прочитать или переместить, UI блокирует изменения
и объясняет, что надо проверить доступ и перезапустить приложение.

## Автоматические проверки

```powershell
& ./.tools/dotnet/dotnet.exe build DesktopOrganizer.sln
& ./.tools/dotnet/dotnet.exe test DesktopOrganizer.sln
```

Результат проверки 1 октября 2026: сборка без ошибок и предупреждений,
41 тест пройден, 0 не пройдено, 0 пропущено.
GUI-сценарий, восстановление после перезапуска, валидация нулевой ширины
и запуск с повреждённым JSON также проверены на запущенном приложении.
