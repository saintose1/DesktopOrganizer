# DesktopOrganizer — Forest UI (0.4.0)

Интерфейс главного окна заменён с Lavender HUD на «Лесной»: тёмный мох и шалфей,
светлая тема на тёплой бумаге, заголовки с засечками, острые углы, линии 1 px.
Без свечения, градиентов на поверхностях и стеклянных карточек. Старое описание Lavender HUD:
[UI-DESIGN-MAGICPATH.md](UI-DESIGN-MAGICPATH.md) (история).

## Как это получилось

Референсы сгенерированы в ChatGPT (чат «Дизайн лесного интерфейса») и лежат локально в `design/refs/` (22 МБ, в Git не входят)
(1586×992, баннер 1920×819, листы значков и мха на фоне `#FF00FF`). В WPF они **не вставлены как картинки**:
экраны пересобраны в XAML, из референсов взяты цвета, пропорции и три ассета.

| Ассет | Откуда | Где используется |
| --- | --- | --- |
| `Assets/Forest/banner.jpg` | `do-ref-05` (обрезка 1920×300) | баннер страницы «Обзор» |
| `Assets/Forest/icon-*.png` (30 шт.) | `do-ref-11`, сетка 6×5, фон вырезан | декоративные значки категорий на «Обзоре» и в предпросмотре |
| `Assets/Forest/moss-*.png` (8 шт.) | `do-ref-04`, сетка 4×2, фон вырезан | `moss-frond` — папоротник в заголовке окна и у активного пункта меню |

Нарезка и удаление розового фона: сохранённый в истории сессии PowerShell-скрипт на `System.Drawing`
(ключ по `min(R,B) − G`, снятие каймы). Для повторной нарезки нужны исходные листы из `design/refs/`.

## Страницы

- **Обзор** — баннер, строка статистики («4 группы | 12 элементов | 3 правила», склонение по языку),
  карточки групп с категорийными значками, поиск по группам и именам значков. Клик по карточке открывает группу.
  Значки здесь — декоративные картинки категории по расширению, **не копии настоящих значков Explorer**.
  На рабочем столе значки по-прежнему настоящие (см. AGENTS.md).
- **Группы** — список слева, редактор справа (заголовок, панель, фон, рамка, авто-сортировка), живой предпросмотр
  группы и кнопка «Лесной стиль» (Georgia/Noto Serif, `#E4E6D3` / `#14221A` 85% / рамка `#86A35F` 60%).
  Остальные существующие группы и значения по умолчанию **не меняются**.
- **Правила** — плоский список масок авто-сортировки всех групп (маска → группа), добавление и удаление,
  предпросмотр совпадений с файлами рабочего стола (пользовательский и общий). Хранение прежнее: маски лежат в группе
  (`Fence.AutoSort`); страница меняет их тем же путём «сохранить → обновить модель».
  Сверху раскрывающаяся подсказка «Как это работает» (что такое маска, три шага, примеры: `*.exe`, `*.lnk`,
  `*.pdf; *.docx`, `Steam*`, `*отчёт*`, короткая запись `pdf`); под полем маски — кнопки готовых масок
  (программы, ярлыки, документы, таблицы, картинки, видео, музыка, архивы).
- **Настройки** — язык, автозапуск, **тема (как в Windows / светлая / тёмная)**, hover-раскрытие, длительности анимаций.

Раздела «Профили» из референса нет: у него нет реализации в приложении, а AGENTS.md запрещает
фиктивные реализации будущих сервисов.

## Архитектура

- `Themes/ForestDark.xaml`, `ForestLight.xaml` — только палитра (одинаковые ключи).
  `Themes/ForestControls.xaml` — стили элементов управления на `DynamicResource`, поэтому тема меняется на лету.
- `Themes/ThemeManager` подменяет палитру в `Application.Resources`; «как в Windows» читает
  `AppsUseLightTheme` и следит за `SystemEvents.UserPreferenceChanged`.
- `AppPreferences.Theme` (`"dark"`/`"light"`/`null`) хранится в `settings.json`; старые файлы читаются как «как в Windows».
- `MainWindowViewModel` стал `partial`: `.Overview.cs` (карточки, статистика, `ForestIcons`), `.Rules.cs` (страница правил).
  Страницы — `AppPage`; `IsFencesPage`/`IsSettingsPage` сохранены.
- Шрифт заголовков: `Noto Serif, Georgia, Cambria`. Значки интерфейса — Segoe Fluent Icons / Segoe MDL2 Assets.
- Все новые строки проходят через `{l:Tr}` / `Texts.T`; английские переводы добавлены.

## Проверка

- Debug/Release: 0 предупреждений/ошибок, 400 тестов (новые — `ForestUiTests`).
- GUI: `DesktopOrganizer.App.exe --StorageDirectory <папка> --NoDesktop=true` открывает окно без подключения
  к рабочему столу (для проверки рядом с работающей копией). Проверены на копии данных: все страницы в обеих темах,
  английский язык, добавление правила, «Лесной стиль», переключение темы.
- **Не проверено физически:** внешний вид самой группы на рабочем столе с «Лесным стилем» поверх обоев
  (Wallpaper Engine), mixed DPI, высокий контраст.

## Раскрытие без задержки

Причина прежней задержки (по логам и коду): значки свёрнутых групп постоянно были скрыты атрибутом Hidden, а Explorer
показывает скрытые элементы обратно только примерно через 0,6 с. Подготовка при подходе курсора срабатывала лишь в зоне
сбоку и снизу от заголовка, а hover-раскрытие начинается сразу, поэтому рамка раскрывалась без значков.

Теперь (`ConcealmentPolicy`, по умолчанию «мгновенное раскрытие»):

- в простое значки свёрнутых групп просто припаркованы за экраном и остаются в Explorer, так что раскрытие сразу
  анимирует их вместе с рамкой;
- атрибут Hidden ставится только когда начинается перетаскивание значков рабочего стола (именно drop выталкивал
  припаркованные значки); клик и двойной клик Explorer не трогают;
- через 1,5 с тишины после жеста скрытые значки возвращаются в парковку одним обновлением Explorer;
- прежний режим включается в Настройках: «Всегда скрывать значки свёрнутых групп» (без вспышек даже при перетаскивании
  из других окон, но раскрытие ждёт Explorer).

Кривые: раскрытие — cubic ease-out (как было), сворачивание — quadratic ease-out вместо ease-in-out (раньше первые 25 %
времени рамка почти стояла). Обе без перелёта.

Остаточный риск мгновенного режима: перетаскивание в рабочий стол **из другого окна** или очень быстрый drop
(меньше ~0,5 с) может на кадр вытолкнуть припаркованные значки; существующее самовосстановление паркует их обратно.

## Анимации окна

`Views/Motion` — плавное появление страниц (прозрачность + сдвиг 10 px, 240 мс), листа папоротника у активного пункта
меню, раскрывающихся разделов редактора; лёгкий подъём карточек «Обзора» при наведении. Трансформации создаются
в коде для каждого элемента. При выключенных «Эффектах анимации» Windows элементы появляются сразу.
